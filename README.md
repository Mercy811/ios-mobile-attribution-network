# iOS Mobile Attribution Network

An interactive map showing where each component in an iOS mobile-attribution flow lives and what information travels between them.

The visualization covers the end user, an ad platform, the App Store, an app, an MMP SDK and backend, attribution matching, the Amplitude SDK, and the Amplitude backend.

## Run locally

This is a dependency-free static page. Open `index.html` in a browser or serve the directory with any static HTTP server.

## Deployment

GitHub Pages publishes directly from the `main` branch root.
